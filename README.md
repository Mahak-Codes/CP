# 🚀 Competitive Programming Repository

Welcome to my Competitive Programming (CP) repository!  

This is a collection of my solutions to coding problems from various platforms such as **Codeforces**, **LeetCode**, **CodeChef**, and **AtCoder**. It reflects my journey in learning Data Structures and Algorithms and sharpening my problem-solving skills.


## 🧠 What You'll Find

This repository contains solutions to various competitive programming problems, mainly in C++. The problems are categorized across different platforms and topics. Here's a brief overview of the contents:

### Platforms:
- **Codeforces**: Solutions to problems from Codeforces contests.
- **Codechef**: Problems solved from Codechef contests.
- **Atcoder**: Solutions from Atcoder problems and contests.
- **CSES**: Solutions to problems from the CSES Problem Set.

### Topics:
- **Data Structures**: Problems related to arrays, linked lists, stacks, queues, etc.
- **Algorithms**: Problems involving sorting, searching, dynamic programming, and graph algorithms.
- **Mathematics**: Problems involving number theory, combinatorics, etc.
- **Miscellaneous**: Solutions to other types of problems not falling into the categories above.
